## What it is

- Local-first macOS app for planning and running AI-agent coding work
- The ticket carries everything: plan, starting context, an isolated git worktree, the live diff/change-set review, the project history
- Sessions are durable event ledgers — survive process death, terminal recreation, app relaunch

## Why

- Context evaporates between planning and doing in every agent tool
- Deliberately ONE structured runtime (Pi) instead of an adapter layer — OpenCode was the original backend, ripped out mid-build ("Session 7", ~aug 8) to stop doing capability-parity plumbing
- Claude Code / Codex / etc. still run in embedded terminals as manual companions

## Raw material (keep or cut)

- ~289k lines TS, 1,230 commits, 104 merged PRs in ~5.5 weeks; peak week: 361 commits
- Commit authors include "Claude" and "Codex" — the tool for running coding agents was built by coding agents
