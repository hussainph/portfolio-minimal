## What is it?

Volli is an open-source macOS app for planning and running AI-agent coding work. I built it on a "zoom-in or zoom-out" philosophy: let an orchestrator manage my sessions in parallel, or let me manage my engineering process myself, or let me work with raw code easily. A large part of the product design is dedicated to integrating these three modes neatly. Volli is free forever for local singleplayer use.

## Why build it?

I built Volli because my workflow for long-term engineering projects was increasingly fragmented; I was using Linear to do task-tracking, cmux to manage my terminal sessions across my coding agents, and keeping a Zed instance open for code changes. Once I fell into a rhythm in terms of orchestrating tasks to build software long-term, I realized I could package it up into a better UX for myself.

Also, Volli is a love letter to every app experience I've enjoyed over the past few years in this wild AI era. It's an amalgamation of great ideas, made to fit how I work with agents.

## Timeline
- Volli v1 was built over Christmas 2025 (a.k.a. when "coding was solved") as a cloud-native, knowledge work web product.
- I later backed off that idea when I realized most individual consumers aren't trying to organize their lives in agent kanban boards.
- In July 2026, I niched down to a macOS native app specifically focused on orchestrating AI-agent coding work.
- Started Volli v2 as a cmux+kanban-style app to manage terminal sessions, but realized there was more product opportunity and flexibility if I integrated one core harness (Pi) instead.
- Now building on top of the Pi harness to provide a unified, AI-agent-focused coding experience.
- Current day: Volli is live in alpha! I'm working on adding subagent support, MCP integrations, better agent automations and more UX improvements.
- Next: multiplayer, mobile and cloud support! We're trying to close the lid, physically and proverbially. The goal is to make it so you can coordinate and check in with your agents from anywhere, all while sharing work with your team.
